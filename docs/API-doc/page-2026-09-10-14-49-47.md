# Daily Transaction Data

Returns daily close price, volume, and market cap for a given IDX symbol over a date range of up to 90 days.

IDX symbol: 4 letters, optionally followed by `.jk` (case-insensitive). E.g. `BBCA`, `GOTO`, `TLKM`.

Date range: defaults to last 30 days. Max window 90 days; wider ranges are clamped to the most recent 90 days ending at `end`. Future `end` dates return 400.

Costs 1 API credit.

GET

/

v2

/

daily

/

{symbol}

/

#### Authorizations

[​

](#authorization-authorization)

Authorization

string

header

required

Global API Key Authorization

#### Path Parameters

[​

](#parameter-symbol)

symbol

string

required

IDX symbol. E.g. `BBCA`, `GOTO`, `TLKM`.

#### Query Parameters

[​

](#parameter-start)

start

string

Start date in `YYYY-MM-DD` format. Defaults to 30 days before `end`. Wider ranges are clamped to the most recent 90 days.

[​

](#parameter-end)

end

string

End date in `YYYY-MM-DD` format. Defaults to today. Future dates return 400.
