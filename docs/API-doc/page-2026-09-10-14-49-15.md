# Company Revenue Segments

Returns a Sankey-graph-ready revenue and cost segment breakdown for a given company and financial year. Not all companies have segment data — use the [Companies with Revenue Segments](https://docs.sectors.app/api-references/v2/indonesia/helper-list/companies-segments-list) endpoint to check availability.

IDX symbol: 4 letters, optionally followed by `.jk` (case-insensitive). E.g. `BUMI`, `TLKM`, `ASII`.

Costs 1 API credit.

GET

/

v2

/

company

/

get-segments

/

{symbol}

/

#### Authorizations

](#authorization-authorization)

Authorization

string

header

required

Global API Key Authorization

#### Path Parameters

[​

](#parameter-symbol)

symbol

string

required

IDX symbol symbol. E.g. `BUMI`, `TLKM`. Not all companies have segment data — check the [Companies with Revenue Segments](https://docs.sectors.app/api-references/v2/indonesia/helper-list/companies-segments-list) helper first.

#### Query Parameters

[​

](#parameter-financial-year)

financial\_year

integer

Financial year to retrieve. Defaults to the latest available year.

Required range: `1900 <= x <= 2026`
