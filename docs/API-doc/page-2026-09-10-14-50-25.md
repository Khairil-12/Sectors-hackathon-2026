News & Filings

# News Articles

Returns paginated news articles from either the IDX (Indonesian Stock Exchange) or mining news sources. Use the `extension` parameter to choose the data source — each extension has its own set of valid filter parameters.

Mixing IDX and mining parameters will return a 400 error. E.g. passing `sector` with `extension=mining` is invalid.

IDX Extension Parameters (extension=idx)

-   **sector**: Comma-separated sector slugs (kebab-case). Get values from the [Subsectors](https://docs.sectors.app/api-references/v2/indonesia/helper-list/subsectors) endpoint.
-   **sub\_sector**: Comma-separated subsector slugs (kebab-case). E.g. `banks`, `insurance`, `retailing`. Get valid values from the [Subsectors](https://docs.sectors.app/api-references/v2/indonesia/helper-list/subsectors) endpoint.
-   **tags**: Comma-separated tag slugs. Get values from the [News Tags](https://docs.sectors.app/api-references/v2/indonesia/helper-list/tags) endpoint.
-   **symbols**: Comma-separated IDX symbols. E.g. `BBCA,BBRI,BMRI`.
-   **keyword**: Case-insensitive substring match on article title.

Mining Extension Parameters (extension=mining)

-   **keyword**: Case-insensitive substring match on article title.
-   **commodity\_type**: Filter by commodity. E.g. `Coal`, `Nickel`, `Gold`.

Date filters: both `start` and `end` are independent and optional — omit either side to leave that bound unconstrained. Future `end` dates return 400.

Costs 1 API credit.

#### Authorizations

[​

](#authorization-authorization)

Authorization

string

header

required

Global API Key Authorization

#### Query Parameters

[​

](#parameter-sector)

sector

string

IDX only. Comma-separated sector slugs (kebab-case).

[​

](#parameter-sub-sector)

sub\_sector

string

IDX only. Comma-separated subsector slugs (kebab-case).

[​

](#parameter-commodity-type)

commodity\_type

enum<string>

Mining only. Filter by commodity type. E.g. `Coal`, `Nickel`.

Available options:

`Bauxite`,

`Coal`,

`Copper`,

`Gold`,

`Iron`,

`Nickel`,

`Non-Metallic Mineral`,

`Sand, Stone, Gravel`,

`Tin`

[​

](#parameter-start)

start

string

Start date in `YYYY-MM-DD` format. Optional; if omitted, no lower bound is applied. Filters on `timestamp`.

[​

](#parameter-end)

end

string

End date in `YYYY-MM-DD` format. Optional; if omitted, no upper bound is applied. Future dates return 400.

[​

](#parameter-limit)

limit

integer

default:20

Items per page. Max 30.

Required range: `1 <= x <= 30`

[​

](#parameter-offset)

offset

integer

default:0

Items to skip for pagination.

Required range: `x >= 0`

[​

](#parameter-tags)

tags

string

IDX only. Comma-separated tag slugs. Get valid values from the [News Tags](https://docs.sectors.app/api-references/v2/indonesia/helper-list/tags) endpoint.

[​

](#parameter-extension)

extension

enum<string>

default:idx

Data source. Default `idx`.

Available options:

`idx`,

`mining`

[​

](#parameter-keyword)

keyword

string

Case-insensitive substring match on article title. Works for both IDX and mining.

[​

](#parameter-symbols)

symbols

string

IDX only. Comma-separated IDX symbols. E.g. `BBCA,BBRI`.
