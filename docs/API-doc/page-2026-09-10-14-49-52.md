# IDX Market Summary

Returns historical total IDX market capitalization for a date range of up to 90 days.

Earliest available data is from **January 1, 2021**. Requesting earlier dates returns 400.

Date range: defaults to last 30 days. Max window 90 days; wider ranges are clamped to the most recent 90 days ending at `end`. Future `end` dates return 400.

Costs 1 API credit.

#### Authorizations

[​

](#authorization-authorization)

Authorization

string

header

required

Global API Key Authorization

#### Query Parameters

[​

](#parameter-start)

start

string

Start date in `YYYY-MM-DD` format. Earliest valid: `2021-01-01`. Defaults to 30 days before `end`. Wider ranges are clamped to the most recent 90 days.

[​

](#parameter-end)

end

string

End date in `YYYY-MM-DD` format. Defaults to today. Future dates return 400.

#### Response

200

application/json

Array of daily IDX total market cap records.

](#response-items-date)

date

string<date>

required

[​

](#response-items-idx-total-market-cap)

idx\_total\_market\_cap

integer

required
