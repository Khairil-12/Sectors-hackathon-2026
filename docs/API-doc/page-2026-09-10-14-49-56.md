# Index Daily Transaction Data

Returns daily closing price for a given IDX index over a date range of up to 90 days.

Earliest available data is from **January 2, 2019**.

Available index codes

`ftse`, `idx30`, `idxbumn20`, `idxesgl`, `idxg30`, `idxhidiv20`, `idxq30`, `idxv30`, `ihsg`, `jii70`, `kompas100`, `lq45`, `sminfra18`, `srikehati`, `sti`, `economic30`, `idxvesta28`

Date range: defaults to last 30 days. Max window 90 days; wider ranges are clamped to the most recent 90 days ending at `end`. Future `end` dates return 400.

Costs 1 API credit.

#### Authorizations

[​

](#authorization-authorization)

Authorization

string

header

required

Global API Key Authorization

#### Path Parameters

[​

](#parameter-index-code)

index\_code

string

required

Index code. E.g. `lq45`, `ihsg`, `idx30`.

#### Query Parameters

[​

](#parameter-start)

start

string

Start date in `YYYY-MM-DD` format. Defaults to 30 days before `end`. Wider ranges are clamped to the most recent 90 days.

[​

](#parameter-end)

end

string

End date in `YYYY-MM-DD` format. Defaults to today. Future dates return 400.

#### Response

200

application/json

Array of daily index price records.

[​

](#response-items-index-code)

index\_code

string

required

Index code (e.g. IDX30, LQ45).

[​

](#response-items-date)

date

string<date>

required

Trading date.

[​

](#response-items-price)

price

number<double>

required

Index closing price.
