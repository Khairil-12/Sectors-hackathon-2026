# Top Brokers Daily Ranking

Brokers ranked by gross trade value (default) or absolute net flow for a single date. Optionally filter by `origin` (foreign/domestic) and `cohort` (retail/mixed/institutional/unknown). Returns all matching brokers if `n_brokers` is omitted.

Origin and cohort classifications come from the broker registry. Retrieve the full list with these classifications from the [Broker Registry](https://docs.sectors.app/api-references/v2/indonesia/brokers/broker-registry) endpoint.

Costs 2 API credits.

#### Authorizations

[​

](#authorization-authorization)

Authorization

string

header

required

Global API Key Authorization

#### Query Parameters

[​

](#parameter-cohort)

cohort

enum<string>

Filter by broker cohort (case-insensitive). Default `all`.

Available options:

`all`,

`institutional`,

`mixed`,

`retail`,

`unknown`

[​

](#parameter-date)

date

string

Target date (YYYY-MM-DD). Default: latest available.

[​

](#parameter-metric)

metric

enum<string>

`gross` ranks by total buy + sell value; `net` ranks by absolute net flow. Default `gross`.

Available options:

`gross`,

`net`

[​

](#parameter-n-brokers)

n\_brokers

integer

How many brokers to return. Default: all matching (~88 total). Max 90.

Required range: `1 <= x <= 90`

[​

](#parameter-origin)

origin

enum<string>

Filter by broker origin. Default `all`.

Available options:

`all`,

`domestic`,

`foreign`
