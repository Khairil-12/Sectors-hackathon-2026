# Company Filings

Returns IDX insider trading filings — buy/sell transactions by company insiders and major shareholders. Supports filtering by sector, subsector, tags, symbol, transaction type, holder\_type, and date range.

IDX symbol: 4 letters, optionally followed by `.jk` (case-insensitive). E.g. `BBCA`, `BMRI`, `TLKM`.

Date filters: both `start` and `end` are independent and optional — omit either side to leave that bound unconstrained. Future `end` dates return 400.

Costs 1 API credit.

#### Authorizations

[​

](#authorization-authorization)

Authorization

string

header

required

Global API Key Authorization

#### Query Parameters

[​

](#parameter-symbol)

symbol

string

IDX symbol symbol to filter by. E.g. `BBCA`, `BMRI`.

[​

](#parameter-sector)

sector

string

Kebab-case sector slug. E.g. `healthcare`, `financials`. Get valid values from the [Subsectors](https://docs.sectors.app/api-references/v2/indonesia/helper-list/subsectors) endpoint.

[​

](#parameter-sub-sector)

sub\_sector

string

Kebab-case subsector slug. E.g. `banks`, `tobacco`. Get valid values from the [Subsectors](https://docs.sectors.app/api-references/v2/indonesia/helper-list/subsectors) endpoint.

[​

](#parameter-start)

start

string

Start date in `YYYY-MM-DD` format. Optional; if omitted, no lower bound is applied. Filters on `timestamp`.

[​

](#parameter-end)

end

string

End date in `YYYY-MM-DD` format. Optional; if omitted, no upper bound is applied. Future dates return 400.

[​

](#parameter-limit)

limit

integer

default:20

Number of results to return. Maximum: 30.

Required range: `1 <= x <= 30`

[​

](#parameter-offset)

offset

integer

default:0

Number of results to skip for pagination.

Required range: `x >= 0`

[​

](#parameter-transaction-type)

transaction\_type

enum<string>

Filter by transaction direction: `buy`, `sell`, or `others`.

Available options:

`buy`,

`others`,

`sell`

[​

](#parameter-tags)

tags

string

Comma-separated tag slugs. E.g. `Bullish,insider-trading`. Get valid values from the [News Tags](https://docs.sectors.app/api-references/v2/indonesia/helper-list/tags) endpoint.

[​

](#parameter-holder-type)

holder\_type

enum<string>

Filter by holder type (case-insensitive).

Available options:

`corporate-investor`,

`insider`,

`institution`

application/json

Paginated list of insider trading filings.
