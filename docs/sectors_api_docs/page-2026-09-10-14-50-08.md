# Most Traded Stocks

Returns the most traded IDX stocks by transaction volume over a date range of up to 90 days. Results are keyed by date.

Date range: defaults to last 30 days. Max window 90 days; wider ranges are clamped to the most recent 90 days ending at `end`. Future `end` dates return 400.

Costs 2 API credits.

#### Authorizations

[​

](#authorization-authorization)

Authorization

string

header

required

Global API Key Authorization

#### Query Parameters

[​

](#parameter-sub-sector)

sub\_sector

string

Filter by kebab-case subsector slug. E.g. `banks`. Get valid values from the [Subsectors](https://docs.sectors.app/api-references/v2/indonesia/helper-list/subsectors) endpoint.

[​

](#parameter-start)

start

string

Start date in `YYYY-MM-DD` format. Defaults to 30 days before `end`. Wider ranges are clamped to the most recent 90 days.

[​

](#parameter-end)

end

string

End date in `YYYY-MM-DD` format. Defaults to today. Future dates return 400.

[​

](#parameter-adjusted)

adjusted

boolean

default:false

If `true`, rank by volume × closing price instead of raw volume.

[​

](#parameter-n-stock)

n\_stock

integer

default:5

Number of tickers per day. Default 5, max 10.

Required range: `1 <= x <= 10`

#### Response

200

application/json

Dictionary keyed by trading date (`YYYY-MM-DD`). Each value is an array of `{symbol, company_name, volume, price}` objects.
