IPO & Performance

# Company IPO & Listing Performance

Returns price change percentages since listing date for a given IDX-listed symbol, across 7, 30, 90, and 365-day windows.

Listing performance data is only available for tickers listed **after May 2005**.

IDX symbol: 4 letters, optionally followed by `.jk` (case-insensitive). E.g. `GOTO`, `BREN`, `BUKA`.

Costs 1 API credit.

GET

/

v2

/

listing-performance

/

{symbol}

/
